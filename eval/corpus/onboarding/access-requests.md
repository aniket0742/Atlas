# Access Requests

## How to request

All access is requested through the access portal, never by asking someone
directly in chat. A direct grant leaves no record, and an access grant with no
record cannot be reviewed or revoked reliably.

## Approval

Standard access is approved by your manager. Production database access and
customer data access additionally require a second approver from the security
team.

## Time-bound by default

Elevated access expires after 8 hours and must be re-requested. Permanent
elevated access is granted only for named service accounts, never for people.

## Break-glass

Emergency access bypasses the approval queue and is granted immediately. Every
break-glass use is reviewed the following business day, and using it is never
itself a problem. Not declaring it afterwards is.

## Offboarding

Access is revoked within one hour of an offboarding request. Quarterly access
reviews catch anything the automated revocation missed.
